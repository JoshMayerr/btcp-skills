# Value creation and portfolio hiring

For each operating workstream show evidence, baseline, problem/opportunity, required analysis, owner, KPI, 30/60/90-day action, board reporting, dependencies, and investment-case impact. Distinguish findings, post-close hypotheses, and management commitments. Include M&A only when strategy, readiness, and evidence support it.

## Hiring workflow

When requested or relevant, monitor careers pages/ATS while respecting access terms; store raw description, requisition ID, timestamp, and URL; detect new, edited, closed, and reposted roles; extract title, location, compensation, reporting line, duties, systems, credentials, and experience; map language to operating hypotheses; and create a structured search specification.

Search permitted public professional sources for possible candidates. Record match rationale and missing qualifications; verify current role, tenure, location, and credentials; flag stale/indirect evidence. Exclude protected characteristics, minimize personal data, require human verification before actionability, and perform no outreach without authorization.

Track sourced, verified, approved, contacted, screened, interviewed, referenced, offered, and accepted stages; calculate requisition/stage aging; produce daily alerts and weekly board exceptions only when requested. Every candidate row needs source URLs, access date, confidence, rationale, missing evidence, conflict/sensitivity flag, and next verification step.

The value-creation brief should explain the workflow and include a worked example when evidence supports it. Create a separate hiring workbook only if requested.
